# Первый запуск рабочего агента

Когда владелец впервые отдаёт тебе этот файл, собери его рабочий контекст без длинного интервью.

1. Прочитай `~/.bb/AGENTS.md`, `~/.bb/context/USER_PROFILE.md`, `~/.bb/context/WORKSPACE_MAP.md` и `~/.bb/context/INTEGRATIONS_STATUS.md`.
2. Осмотри только верхний уровень доступных рабочих папок. Не открывай личные документы, переписки, `.env`, менеджеры паролей и каталоги с ключами.
3. По уже доступным данным предложи черновик из пяти пунктов: кто владелец, чем занимается, какие у него главные проекты, где лежат рабочие материалы, как он предпочитает получать результат.
4. Задай одним сообщением только те вопросы, на которые нельзя ответить по фактам. Не спрашивай то, что не понадобится в ближайшей работе.
5. После подтверждения обнови профиль и карту. Не записывай догадки и секреты.
6. Спроси одним списком, какие рабочие сервисы реально нужны сейчас. Подключай только выбранные, каждый через официальный OAuth, и после каждого делай узкую проверку доступа без чтения чужих материалов. Запиши результат и дату в `INTEGRATIONS_STATUS.md`.
7. Попроси одну настоящую небольшую задачу и выполни её до проверенного результата. По ходу зафиксируй только один повторяемый маршрут, если он действительно проявился.

Готово, когда владелец продиктовал задачу через Handy, агент выполнил её в bb, а профиль содержит только подтверждённые сведения.
