# Правила проекта

- Сначала прочитай `PROJECT_CONTEXT.md` и найди существующие источники истины проекта.
- Перед изменением общего файла проверь незакоммиченные изменения и не затирай чужую работу.
- Один факт, число или список должен иметь один источник истины. Не дублируй живые данные вручную в нескольких файлах.
- После изменения выполни уместные тесты и проверь реальный пользовательский сценарий.
- Проектное знание сохраняй здесь; общие привычки владельца не копируй в каждый проект.
