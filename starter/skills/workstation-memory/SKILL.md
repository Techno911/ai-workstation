# Общая память bb

1. Перед повторным исследованием найди запись: `bb memory search "<тема>" --scope all --json`.
2. Раскрой только релевантную: `bb memory get <id> --scope all --json`.
3. Сверь изменчивый факт с живым источником.
4. Новое устойчивое знание добавляй только после проверки. Сначала ищи запись по теме, чтобы обновить её, а не создать дубликат.
5. В память не попадают пароли, токены, персональные сырые данные, временные ошибки, большие логи и предположения.
6. Глобальный уровень — только для привычек и правил, полезных во всех проектах. Путь, команда и архитектура одного проекта хранятся на проектном уровне.
