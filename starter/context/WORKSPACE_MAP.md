# Карта рабочих пространств

Заполняется только по реальным папкам компьютера владельца.

## Рабочие корни

- Не заполнено.

## Что не сканировать без прямой задачи

- `.env*`, ключи, сертификаты, базы паролей;
- личные документы, здоровье, финансы и идентификационные данные;
- `node_modules`, `.git`, кэши, логи, резервные копии и большие медиаархивы.

## Как искать

1. Определи тему задачи и наиболее вероятную папку.
2. Посмотри имена файлов на небольшой глубине.
3. Открывай содержимое только у релевантных кандидатов.
4. Не смешивай материалы разных клиентов и личные данные.
