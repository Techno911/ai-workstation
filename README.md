# Рабочая ИИ‑система на Windows

Готовый стартовый комплект для человека, который много работает с Claude или Codex и хочет ставить задачи голосом, не объяснять контекст заново и хранить рабочие правила независимо от одной модели.

Комплект переносит проверенную механику системы Артёма Чиркова, но не его личные данные: здесь нет переписок, клиентских материалов, паролей, токенов и приватной памяти.

## Самый короткий вход

Отправьте своему ИИ‑агенту одно сообщение:

```text
https://github.com/Techno911/ai-workstation

Ты мой ИИ-агент. Прочитай README по ссылке и полностью разверни эту систему на моём Windows-компьютере. Делай всё, что можешь, самостоятельно. Меня подключай только для перезагрузки, системного разрешения и входа в мою подписку Claude или ChatGPT. Ничего существующего не удаляй и не переноси чужие ключи.
```

Дальше агент ведёт установку сам. Человеку не нужно читать остальную страницу. Условие одного входа: исходный агент уже должен иметь доступ к PowerShell на этом компьютере; обычный веб‑чат без управления компьютером физически не сможет выполнить команды.

---

## Инструкция для ИИ‑агента

Ты разворачиваешь рабочую систему на компьютере владельца. Главный результат: человек нажимает сочетание клавиш, диктует задачу по‑русски, текст появляется в bb, а агент выполняет задачу с постоянными правилами и контекстом.

### Границы

- Целевая система — Windows 10/11 x64. Handy работает нативно в Windows, bb — внутри WSL2.
- Не копируй с чужих компьютеров настройки, базы, историю, токены или файлы памяти.
- Не удаляй существующие настройки. Установщик сам создаёт резервную копию перед изменением Handy и файлов bb.
- Не проси владельца вводить пароль или токен в чат. Вход выполняется только в официальном окне Claude или ChatGPT.
- Не обещай полную автоматизацию: владелец подтверждает UAC, системную перезагрузку, разрешение микрофона и вход в подписку. В редком случае отключённой виртуализации ему придётся включить её в BIOS/UEFI.

### Главный путь

1. Открой PowerShell от имени администратора.
2. Если Git отсутствует, установи его:

   ```powershell
   winget install --id Git.Git -e --accept-package-agreements --accept-source-agreements
   ```

3. Клонируй комплект и запусти установщик:

   ```powershell
   Set-Location $env:USERPROFILE
   if (Test-Path .\ai-workstation) { Set-Location .\ai-workstation; git pull --ff-only } else { git clone https://github.com/Techno911/ai-workstation.git; Set-Location .\ai-workstation }
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-windows.ps1
   ```

4. Владелец подтверждает системный диалог UAC. Если установщик попросил перезагрузку, попроси владельца только перезагрузить компьютер. После входа снова выполни команду из шага 3. Первый запуск Ubuntu может попросить создать локального Linux‑пользователя и пароль — это делает владелец прямо в системном окне, не сообщая пароль тебе.
5. Проверь результат:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-windows.ps1
   ```

6. Внутри Ubuntu выполни вход в тот сервис, которым владелец уже пользуется. По умолчанию для этого комплекта выбери Claude:

   ```powershell
   wsl -d Ubuntu -- bash -lc "claude auth login"
   ```

   Если у владельца подписка ChatGPT и он предпочитает Codex:

   ```powershell
   wsl -d Ubuntu -- bash -lc "codex login"
   ```

   Открой показанную официальную ссылку в браузере Windows. Владелец подтверждает вход сам.

7. Запусти bb и открой интерфейс:

   ```powershell
   wsl -d Ubuntu -- bash -lc "bb-app start"
   Start-Process "http://localhost:38886"
   ```

8. В bb создай первый личный проект, выбери Claude Code или Codex и отправь агенту файл `~/.bb/context/FIRST_RUN.md`. Агент должен провести тихую инвентаризацию и заполнить шаблоны контекста фактами владельца. Для каждого нового проекта копируй заготовку из `~/.bb/project-template` в его рабочую папку.
9. Запусти Handy. Если Windows покажет запрос доступа к микрофону, владелец один раз нажимает «Разрешить». Нажми `Ctrl + Space`, продиктуй тестовую задачу и снова нажми `Ctrl + Space`.

### Что установщик делает сам

- ставит Handy через официальный пакет winget;
- скачивает Whisper Large v3 Turbo Q8_0 и проверяет его SHA‑256;
- фиксирует русский язык, включает VAD и проверенную текстовую подсказку для терминов;
- отключает LLM‑постобработку, потому что она может менять смысл диктуемой задачи;
- включает удаление слов‑паразитов и безопасную вставку через `Ctrl+V`;
- включает WSL2 с Ubuntu;
- внутри Ubuntu ставит Node.js 22 и закреплённые проверенные версии bb, Claude Code и Codex; существующие установки не обновляет;
- кладёт общие правила, контекстные шаблоны и переносимые навыки в домашний каталог владельца;
- перед заменой любого существующего файла сохраняет датированную резервную копию.

### Почему настройки Handy именно такие

Связку проверяли на реальных русских диктовках длительностью до 182 секунд. Parakeet V3 на длинных записях периодически терял пунктуацию; GigaAM, Canary и Qwen давали более тяжёлые ошибки. Whisper Large v3 Turbo сохранил содержание и работал примерно в 26 раз быстрее реального времени на машине Артёма.

У Whisper поле `custom_words` работает как предыдущий фрагмент текста. Поэтому там не список через запятую, а короткая проза с правильной пунктуацией. Файл `config/handy-prompt.txt` уже адаптирован под частые слова предпринимателя и коуча. Новые термины добавляй предложениями с точками, сохраняя один элемент в `custom_words`.

### Готово, когда

- `verify-windows.ps1` завершился строкой `READY` без красных ошибок;
- в `%APPDATA%\handy\models` лежит проверенная модель размером около 886 МБ;
- Handy по `Ctrl + Space` вставляет русскую диктовку со знаками препинания;
- `wsl -d Ubuntu -- bash -lc "claude --version; codex --version; bb --version"` возвращает версии;
- открывается `http://localhost:38886`, в bb доступен выбранный провайдер;
- первый агент прочитал `FIRST_RUN.md`, заполнил профиль только подтверждёнными фактами и выполнил одну настоящую задачу владельца.

### Если что‑то не получилось

- `winget` отсутствует: обнови «Установщик приложений» из Microsoft Store и повтори главный путь.
- Корпоративная политика блокирует `winget`, WSL или `huggingface.co`: не обходи её; сообщи владельцу точный заблокированный адрес или компонент и останови установку до разрешения администратора.
- Загрузка модели оборвалась или повредилась: просто повтори шаг 3. Скрипт продолжит неполный файл, а при несовпадении SHA‑256 автоматически отложит его и один раз скачает модель с нуля.
- WSL просит перезагрузку: перезагрузи компьютер и повтори шаг 3. Скрипт идемпотентен.
- WSL сообщает, что виртуализация отключена: попроси владельца включить Intel VT‑x или AMD‑V в BIOS/UEFI. Не пытайся менять прошивку автоматически.
- Ubuntu не завершила первый запуск: открой приложение Ubuntu один раз и создай локального пользователя.
- Handy не вставляет текст: открой Windows → «Параметры» → «Конфиденциальность и безопасность» → «Микрофон» и разреши доступ Handy.
- Сочетание `Ctrl + Space` занято: поменяй его в Handy → Settings → General, затем повтори тест.
- bb не видит Claude или Codex: выполни вход из шага 6 внутри той же Ubuntu, затем перезапусти только bb командой `bb-app stop` и `bb-app start`.

## Состав комплекта

- `scripts/setup-windows.ps1` — Windows, Handy, модель и WSL;
- `scripts/setup-wsl.sh` — Node.js, провайдеры, bb и рабочие правила;
- `scripts/verify-windows.ps1` — итоговая проверка;
- `starter/AGENTS.md` — постоянные правила для всех агентов;
- `starter/FIRST_RUN.md` — первая инвентаризация владельца;
- `starter/context/` — профиль и карта рабочих материалов;
- `starter/context/INTEGRATIONS_STATUS.md` — живой реестр подключений без токенов;
- `starter/project-template/` — отдельный контекст и правила для каждого проекта;
- `starter/skills/` — переносимые навыки проверки фактов и коротких инструкций;
- `_qa/transactions.md` — доказательство сокращения действий.
- `_qa/handy-benchmark.md` — фактура выбора модели без личных записей.

## Что проверено, а что нет

Выбор модели распознавания проверен замером на реальных русских диктовках длиной от 10 до 182 секунд: сравнивались пунктуация, сохранность содержания, написание названий и скорость. Фактура замера лежит в `_qa/handy-benchmark.md`.

Установочные скрипты собраны и вычитаны, синтаксис `setup-wsl.sh` проверен, но целиком на живой машине с Windows они пока не прогонялись. Первый запуск на конкретном компьютере может упереться в отключённую виртуализацию, корпоративную политику или занятую горячую клавишу. Если что-то падает, пришлите вывод из терминала: скрипт печатает шаг, на котором остановился, и не трогает уже установленное.

## Безопасность и лицензия

В репозитории нет ключей и личных данных. Модель скачивается из публичного репозитория Handy и принимается только при совпадении опубликованного SHA‑256. Handy обрабатывает голос локально. Claude, Codex и bb используют условия и подписки самого владельца.

Код комплекта — MIT. Handy и bb устанавливаются из их официальных источников и имеют собственные лицензии.
